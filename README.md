## 📖 Sobre o projeto

O **Vida Santa** é um site dedicado à divulgação da vida dos santos católicos, apresentando suas histórias, ensinamentos e orações.

O objetivo é proporcionar aos visitantes uma maneira simples e acessível de conhecer exemplos de fé, caridade, humildade e amor a Deus.

## 🎯 Objetivos

- ✝️ Divulgar a história dos santos católicos.
- 📚 Compartilhar seus ensinamentos e exemplos de vida.
- 🙏 Disponibilizar orações dedicadas aos santos.
- 💻 Utilizar a tecnologia para compartilhar a fé.
- ❤️ Incentivar a prática do bem e a aproximação com Deus.

## 🚀 Funcionalidades

- 📜 Páginas com biografias dos santos.
- 🙏 Orações dedicadas a diferentes santos.
- 🎨 Interface visual temática e organizada.
- 📱 Layout adaptável a diferentes tamanhos de tela.
- 💙 Página para apoiar pessoas necessitadas.
- 📋 Funcionalidade para copiar o código Pix, quando configurado.
